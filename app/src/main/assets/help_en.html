Extended File Manager — User Guide

This guide covers everything the app can do so far. It grows with every update.

Browsing your files

The first time you open the app, tap Choose folder to grant access to a folder on your device (using Android's own folder picker — the app only ever sees what you explicitly choose). Once granted, tap a folder to open it, and use the breadcrumb bar at the top to jump back to any parent folder you've visited.

Where Android can tell us, each file shows which app it most likely came from (for example, a photo from WhatsApp). An exact match is shown plainly; a best guess based on the folder it's in is marked "likely" — the app is upfront about when it isn't certain.

Getting around

  • Tap the ☰ icon (top-left) to open the navigation menu — it lists every area of the app, and grows as new features are added.
  • The sort icon opens a grouped menu (sort-by, then order) instead of a row of separate buttons.
  • Long-press a file or folder to select it for actions that will apply to it (more actions are added as later features land).

Settings

Open Settings from the navigation menu.

  • Appearance — switch between light, dark, or follow-system, and (on Android 12+) use colors taken from your wallpaper.
  • Language — choose English or Hebrew for the app, independent of your device's system language.
  • Permissions — see how many folders you've granted access to, and a shortcut to the system app-settings page.
  • Display and Logs — reserved sections; their real controls arrive in upcoming updates.
